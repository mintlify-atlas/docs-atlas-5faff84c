The `hashicorp/web-unified-docs` repository is a single monorepo that hosts documentation for every HashiCorp product published on [developer.hashicorp.com](https://developer.hashicorp.com). Content lives under `content/<product>/` and is served through a unified API.

## Versioned vs. unversioned products

Most products use **versioned content**: the `content/<product>/` directory contains one sub-directory per supported release (for example, `content/terraform/v1.11.x/`). When you edit documentation for a specific release, you work inside that version folder.

A smaller set of products are **unversioned**: their `content/<product>/` directory holds content directly without version sub-directories. These products publish a single version tracked on `main`.

Unversioned products in this repository:

- `content/hcp-docs/` — all HCP product documentation
- `content/terraform-docs-common/` — shared Terraform cloud documentation
- `content/well-architected-framework/` — Well-Architected Framework
